# PD2307 ABI CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manually triggered GitHub Actions gate that securely consumes private PD2307 evidence and produces an auditable CRC-input report without building or loading a kernel module.

**Architecture:** A dependency-free Python tool joins the private module index to the CRC TSV, filters it by the canonical vivo vermagic, and emits only non-sensitive summaries and selected CRC records. A dedicated workflow downloads an encrypted input bundle using secrets, verifies its digest, decrypts it in a temporary directory, runs the tool in the fixed Android 14/6.1 DDK container, uploads only the sanitized reports, and deletes private material on exit.

**Tech Stack:** Python 3 standard library, POSIX shell, GitHub Actions, `ghcr.io/ylarod/ddk-min:android14-6.1-20260313`.

**Spec:** `/home/Gold/WorkSpace/kernel patch/CODEX_EXECUTION_GUIDE.md`

## Global Constraints

- B1 runs only in GitHub Actions; do not build, load, or test a kernel module locally.
- Target vermagic after trimming outer TSV whitespace is exactly `6.1.145-android14-11-maybe-dirty SMP preempt mod_unload modversions aarch64 vivo`.
- Do not commit, log, or upload kheaders, kernel config, BTF, kallsyms, raw capture archives, decryption keys, or raw private-bundle paths.
- Reject missing, malformed, conflicting, or target-mismatched CRC input; never synthesize a CRC.
- Keep device-only workflow separate from the public GKI matrix and manual-dispatch only.

## Review Focus

- A TSV with wrong header/row width must fail rather than silently selecting records; covered by Task 1 malformed-input tests.
- Repeated `(symbol, CRC)` records may be deduplicated, but one symbol with different CRCs must fail; covered by Task 1 conflict test.
- A non-target vermagic must never appear in `known-crcs.tsv`; covered by Task 1 exact-match test.
- A changed encrypted bundle must fail digest verification before decryption; covered by Task 2 shell/workflow inspection test.
- Sensitive input must never reach an artifact path or workflow log; covered by Task 2 workflow contract test.
